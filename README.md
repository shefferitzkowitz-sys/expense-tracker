# מעקב הוצאות (PWA)

אפליקציית PWA בעברית לאייפון לניתוח הוצאות חודשיות לפי מועד חיוב. כל המידע נשאר במכשיר: אין שרת, אין חשבון, אין Analytics ואין API חיצוני. מבוסס על המפרט `expense_tracker_full_prd_technical_he.docx` (גרסה 1.0, 11.11.2026).

## מה יש
- **דשבורד**: סך חיובים לחודש, אשראי/הוצאות מול הלוואות, קטגוריות (כולל "לא מסווג") ומקורות, עם דריל-דאון. חודש עתידי מסומן כתחזית חלקית.
- **ניתוח**: מגמה חודשית (מאושר מול תחזית), סינון לפי מקור וקטגוריה, השוואת שני חודשים.
- **עסקאות**: לפי חודש חיוב, חיפוש וסינון, יצירה/עריכה/מחיקה, עסקאות בתשלומים, עריכת החזר הלוואה בודד.
- **ייבוא**: כמה צילומי מסך יחד, OCR מקומי (עברית + אנגלית), טבלת סקירה ליד התמונה, תיקון כל שדה, זיהוי כפילויות והחזרי הלוואות, שמירה אטומית. התמונות לא נשמרות.
- **הגדרות**: כרטיסים וימי חיוב, הלוואות, קטגוריות, כללי שיוך, גיבוי מוצפן (AES-GCM + PBKDF2) ושחזור בהחלפה מלאה.

## החלטות מימוש
- יום חיוב 29–31: בחודש קצר החיוב נופל ביום האחרון בחודש.
- מופעי הלוואה מחושבים דינמית (לא נשמרים); שינוי חד-פעמי נשמר כ-`loanOverride`, ושינוי קבוע כ-`amountChanges` מתאריך.
- תשלומים עתידיים של עסקה בתשלומים נשמרים כשורות עם סטטוס `predicted` וקבוצת תשלומים; ייבוא של אותו תשלום מתאחד איתן.
- הלוואה בלי תאריך סיום: תחזית ל-12 חודשים קדימה.

## פיתוח
```
npm install        # מעתיק גם את קובצי ה-OCR ל-public/ocr
npm test           # בדיקות יחידה (חוקי חיוב, תשלומים, הלוואות, כפילויות, פענוח, גיבוי)
npm run build      # בנייה ל-dist/
npm run preview
```
React + TypeScript + Vite, Dexie (IndexedDB), Tesseract.js 5 עם קובצי שפה מקומיים, vite-plugin-pwa. ה-CSP ב-`index.html` מתיר חיבור רק לאותו מקור.
